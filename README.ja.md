# 物件賃貸管理システム

物件賃貸管理のためのフルスタックデスクトップアプリケーション。物件管理、テナント管理、家賃徴収・督促、契約ライフサイクル管理、物件運営、消防管理、財務会計、レポート分析をカバーします。

> **いかなる形式の商用利用も禁止**されています（販売、ライセンス供与、レンタル、商用ホスティング、
> SaaS サービス、商用製品への統合などを含みますが、これらに限定されません）。
> 違反者は法的責任を追及されます。詳細は [LICENSE](./LICENSE) をご参照ください。

## 技術スタック

| 層 | 技術 |
|---|------|
| フロントエンド | Vue 3.5 Composition API + TypeScript |
| UI ライブラリ | Element Plus 2.5（クールトーン中性トークン v2） |
| チャート | ECharts 6 + vue-echarts 8 |
| 状態管理 | Pinia 2.1 |
| バックエンド | Express 4.22 + TypeScript |
| ORM | Sequelize 6.37（デフォルト SQLite、MySQL オプション） |
| 認証 | JWT（アクセス 4h + リフレッシュ 7d） |
| 定期タスク | node-cron（請求書生成 / 督促エスカレーション / 契約期限 / 月次減価償却 / 物件自動化 / 月次レポート / ドアロックパスワード整理、計 7 件） |
| リアルタイム通信 | WebSocket（8 種のイベント） |
| デスクトップパッケージ | Electron 28 + electron-builder（NSIS インストーラー、compression: normal） |

## クイックスタート

### 前提条件

- Node.js ≥ 18
- npm ≥ 9

### インストールと起動

```bash
# 1. 依存関係のインストール
npm install

# 2. 開発サーバー起動（フロントエンド + バックエンド並行）
npm run dev
```

- フロントエンド: http://localhost:5173
- バックエンド: http://localhost:3001
- デフォルトログイン: `admin / admin123`

### ビルドとパッケージ

```bash
npm run build          # 全体ビルド（フロントエンド → バックエンド → Electron）
npm run build:electron # Electron インストーラのみパッケージ
```

> パッケージ前に dev を停止してください（`backend/node_modules` と `runtime/node/node.exe` がロックされ EPERM になります）。`electron-builder.yml` は `compression: normal`／NSIS のみで、所要は実測約 6 分。成果物は `release/`（`property-rental-system-setup-<version>.exe` + blockmap + `latest.yml`）で、zip 配布物は生成しません。

### データベース切替

デフォルトは SQLite（ゼロ設定）。MySQL に切り替えるには `backend/.env` を編集：

```env
DB_DIALECT=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=property_rental
```

## 外部サービス

4 種類の通知系サービスはいずれも**自社開発の実実装・サードパーティ SDK ゼロ**（Node 組み込みモジュールとグローバル `fetch` のみ）で、`.env` にアカウントキーを記入すれば有効になります。**未設定時は自動的に Mock へ降格してログ出力し、業務フローを止めることはありません**：

| サービス | 実装の要点 | 未設定時 |
|------|---------|---------|
| SMS 通知 | Alibaba Cloud V1 署名（HMAC-SHA1）+ Tencent Cloud TC3-HMAC-SHA256 | Mock ログ出力 |
| 電子印鑑 | eSignBao（e签宝）オープンプラットフォーム v3（token キャッシュ + 同時実行の重複排除 + ステータスマッピング） | Mock ログ出力 |
| メール通知 | 内蔵 SMTP クライアント（node:tls/net、STARTTLS + RFC 2047 中国語件名） | Mock ログ出力 |
| WeChat 通知 | 公式アカウントのテンプレートメッセージ（access_token キャッシュ + 40001 自動リトライ） | Mock ログ出力 |
| 身分証カードリーダー | 華視 CVR-100U：32 ビット Python ブリッジ + 内蔵 WHQL ドライバ + 構造化 API | Mock モードに切替可能 |
| スマートメーター | bzp.iyunmu.com プリペイドプラットフォーム連携、セッションウィンドウ内で token を同期 | プラットフォームアカウントが必要 |
| 銀行照合 / 支払コールバック | Provider インターフェースを予約 | Mock ログ出力 |

アルゴリズム自己診断（実アカウント不要）：`cd backend && npx tsx ../scripts/verify-external-providers.ts`（21 ケース）。
