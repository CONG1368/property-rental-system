# 物件賃貸管理システム

物件賃貸管理のためのフルスタックデスクトップアプリケーション。物件管理、テナント管理、家賃徴収・督促、契約ライフサイクル管理、財務会計、レポート分析をカバーします。

## 技術スタック

| 層 | 技術 |
|---|------|
| フロントエンド | Vue 3 Composition API + TypeScript |
| UI ライブラリ | Element Plus |
| チャート | ECharts 5 + vue-echarts |
| 状態管理 | Pinia |
| バックエンド | Express + TypeScript |
| ORM | Sequelize 6（デフォルト SQLite、MySQL オプション） |
| 認証 | JWT（アクセス 4h + リフレッシュ 7d） |
| 定期タスク | node-cron（請求生成/督促/減価償却/契約期限） |
| リアルタイム通信 | WebSocket |
| デスクトップパッケージ | Electron + electron-builder（NSIS インストーラー） |

## クイックスタート

### 前提条件

- Node.js ≥ 18
- npm ≥ 9

### インストールと起動

```bash
# 1. 依存関係のインストール
npm install

# 2. 開発サーバー起動（フロントエンド + バックエンド並行）
npm run dev
```

- フロントエンド: http://localhost:5173
- バックエンド: http://localhost:3001
- デフォルトログイン: `admin / admin123`

### ビルドとパッケージ

```bash
npm run build          # 全体ビルド（フロントエンド → バックエンド → Electron）
npm run build:electron # Electron インストーラのみパッケージ
```

### データベース切替

デフォルトは SQLite（ゼロ設定）。MySQL に切り替えるには `backend/.env` を編集：

```env
DB_DIALECT=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=property_rental
```

```
│   └── src/
│       ├── models/            # Sequelize モデル（28以上）
│       ├── routes/            # API ルート（24以上モジュール）
│       ├── services/          # ビジネスサービス層（19以上サービス）

├── scripts/                   # ユーティリティスクリプト
├── electron-builder.yml       # パッケージ設定
└── package.json               # ルート設定
```

## 機能一覧

### 賃貸管理

| 機能 | 説明 |
|------|------|
| 物件管理 | 物件情報登録、状態追跡、面積/間取り/費用基準、一括インポート |
| テナント管理 | テナント情報、契約関連付け、信用スコアリング |
| 家賃徴収 | 請求書生成、手動作成、入金記録、費用明細（家賃/水道/電気/管理費/その他） |
| スマート督促 | 3段階督促エスカレーション、督促タスク追跡、延滞マーキング |
| ドアロック管理 | スマートロック（リモート解錠/パスワード管理/バッテリー監視）、従来型ロック（鍵貸出返却/紛失届/無効化フロー）、操作ログ |
| 印刷 | 契約書/領収書/請求書/テナント情報の印刷、ネイティブ印刷＆PDF出力、A4/感熱紙レシート対応 |
| 徴収ダッシュボード | 徴収率、延滞率、支払チャネル分布、賃料推移 |
| 徴収カレンダー | 月間徴収カレンダー表示、一括ステータス概要 |

### 契約管理

| 機能 | 説明 |
|------|------|
| 契約一覧 | 全ライフサイクル: 起草/承認/署名/履行/期限切れ |
| 契約作成 | フォーム式作成、費用設定（水道/電気/管理費）、物件・テナント関連付け |
| 契約承認 | 提出/却下/署名フロー、承認記録追跡 |
| 契約詳細 | 全情報表示、費用設定カード、ファイルアップロード＆ダウンロード |
| 契約カンバン | 状態別8列カンバン |
| 更新管理 | 期限前マルチ期間プレビュー（7/30/90/180/365日）、ワンクリック更新 |
| 期限カレンダー | 月間期限契約表示、マルチレベル期限統計 |
| 契約テンプレート | テンプレート管理 |
| コンプライアンス | 契約コンプライアンス審査 |

### 財務管理

| 機能 | 説明 |
|------|------|
| 帳簿管理 | マルチ帳簿サポート |
| 勘定科目 | 標準26科目体系 |
| 仕訳伝票 | 自動生成（家賃→伝票）、手動入力 |
| 経費管理 | 修繕/清掃/警備/造園/事務/減価償却の経費分類 |
| 税務管理 | 税額計算とエクスポート |
| 予算管理 | 予算編成/審査/実行追跡 |
| レポートセンター | 収入レポート、支出レポート、利益分析 |
| 財務ダッシュボード | 主要財務指標の概要 |

### システム設定

| 機能 | 説明 |
|------|------|
| ユーザー管理 | ユーザー CRUD、ロール権限 |
| 辞書管理 | システム辞書設定 |
| 印刷設定 | 会社ロゴ/印鑑/名称設定、リアルタイムプレビュー |
| 監査ログ | 操作監査追跡 |

## 定期タスク

| タスク | スケジュール | 説明 |
|------|------|------|
| 請求書生成 | 毎日 02:00 | 契約サイクルに基づく自動請求生成 |
| 督促エスカレーション | 毎日 08:00 | 延滞請求の督促レベル自動引上げ |
| 契約期限マーク | 毎日 07:00 | 期限切れ契約状態の自動更新 |
| 月次減価償却 | 毎月1日 02:00 | 固定資産の月次減価償却 |

## 外部サービス（モックモード）

以下のサービスは現在モックモードで動作します（ログファイルに出力）。実際のSDKに接続して本番環境に切替可能：

- 電子署名（eSignBao / Fadada）
- SMS 通知（Alibaba Cloud SMS / Tencent Cloud SMS）
- WeChat / メール通知（WeChat テンプレートメッセージ / Nodemailer）
- 銀行照合
- 支払いコールバック（WeChat Pay / Alipay）
