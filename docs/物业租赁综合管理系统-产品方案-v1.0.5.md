## 项目背景

<!-- cards:3 | 行业痛点=传统物业管理普遍采用纸质台账或Excel管理，数据分散、查询困难、容易出错 | 政策驱动=金税四期上线对财务规范化提出更高要求，租赁合同电子化成为趋势 | 技术机遇=Electron跨平台桌面技术成熟，Vue3/Express等开源框架生态完善 -->

### 行业痛点

- **信息化水平低**：大量中小物业公司仍用纸质台账或Excel管理，缺乏统一的信息系统
- **业财分离严重**：租赁运营与财务管理割裂，收租数据需重复录入财务软件
- **合同管理混乱**：合同条款不统一、审批流程不规范、到期续约无提醒机制
- **催缴效率低下**：依赖人工电话/贴条催缴，逾期管理被动、回款周期长
- **设备与消防台账缺失**：门锁钥匙、消防器材、设施维保、抄表计费散落在多个表格，到期与年检无法预警

### 解决方案

本项目为**桌面端一体化物业租赁管理系统**，将收租管理、财务报表、合同管理、物业运营与消防管理整合在一个应用中，通过 Electron 打包为 Windows 桌面安装包，开箱即用。

<!-- kpi: 服务规模=50~500套房源[#0A3D62] | 支持业态=3种[#F6B93B] | 管理角色=12个[#00B894] | 数据模型=69个[#82CCDD] -->

## 系统定位

<!-- cards:3 | 非SaaS模式=单机部署，数据本地存储，无需互联网连接，保障数据隐私和安全性 | 多业态覆盖=支持公寓、厂房、商铺三种物业业态，一套系统满足混合业态管理需求 | 业财一体化=将租赁运营与会计核算无缝衔接，收租自动生成记账凭证，消除信息孤岛 -->

### 适用范围

| 维度 | 分类 | 说明 |
|------|------|------|
| 物业规模 | 小型（50-100套） | 单机SQLite即开即用 |
| 物业规模 | 中型（100-300套） | 支持切换到MySQL |
| 物业规模 | 大型（300-500套） | MySQL + Redis 缓存加速 |
| 物业业态 | 公寓 | 标准住宅，按套/间管理 |

| 物业业态 | 商铺 | 商业经营，按铺位管理 |

## 核心价值

<!-- cards:3 | 收租管理高效化=自动账单生成+多渠道收款记录+智能四级催缴+数据看板实时监控 | 财务管理规范化=标准26科目体系+双分录凭证+税务计算+报表自动生成 | 合同管理数字化=全生命周期闭环+模板标准化+合规检查+到期自动提醒 -->

## 系统特色

- **一体多模**：运营管理 + 财务核算 + 合同管理 + 物业运营 + 消防管理在同一平台，数据互通无孤岛
- **数据实时互通**：合同签订自动关联房源状态，收租到账自动生成记账凭证，房态变更通过 WebSocket 实时推送
- **业财一体化**：租金收入、水电费用、物业费用直接归集到会计科目，无需手工对账
- **多业态支持**：公寓/厂房/商铺共用一套系统，切换业态类型即可适配
- **可配置权限**：12 个预置角色 × 6 种操作，权限矩阵可按模块定制覆盖默认，越权尝试自动落审计
- **数据安全保障**：JWT 双 Token 认证 + 可配置 RBAC + 全量审计日志 + 不可逆操作二次确认
- **单实例运行**：重复启动只激活已有窗口，不会产生第二个后端进程抢端口
- **弹性扩展能力**：默认 SQLite 零配置，业务增长可平滑切换到 MySQL + Redis
- **外部服务真实可用**：短信/电子签章/邮件/微信均为自研实现（零第三方 SDK），填入密钥即启用，未配置自动降级 Mock

## 房源管理

### 核心功能

- **多业态支持**：公寓/厂房/商铺三种业态，每种业态可自定义子类型
- **楼栋房号体系**：buildingName + roomNumber 双字段，支持楼栋楼层的层级化管理与批量生成
- **9种状态流转**：空置→已锁定→已预订→已出租→退租中→待保洁→待验收→维修中→已冻结，严格状态机规则控制
- **批量导入**：Excel 批量导入房源，自动解析楼栋楼层信息
- **状态变更审计**：每次状态变更均记录 RoomStatusLog（操作人/时间/原状态/新状态/关联合同），仅追加不可修改

### 房态看板

<!-- cards:3 | 主看板=楼栋/楼层筛选+网格卡片+表格视图切换+快捷操作抽屉+批量状态变更 | 数据大屏=暗色主题+ECharts可视化（玫瑰饼图/柱图/仪表盘/热力图/趋势线/桑基图+告警跑马灯） | 批量生成=按楼栋+楼层范围+每层房间数+命名规则自动生成房间 -->

房态变更通过 WebSocket 实时广播（`room:status-changed` / `room:batch-status-changed`），看板前端自动刷新无需手动 F5。

## 租客管理

### 核心功能

- **租客档案**：基本信息、证件信息（支持身份证/营业执照/护照）、联系方式
- **身份证读卡器集成**：华视 CVR-100U 真实接入（32 位 Python 桥 + 内置 WHQL 驱动，可在系统内一键检测安装），身份证号 ISO 7064:1983 MOD 11-2 校验 + NUL 控制字符治理 + 敏感信息脱敏留痕
- **信用评分**：基于缴费及时性、合同履约、物业配合度三维度计算，输出 A/B/C/D 四个信用等级
- **租客关联**：一个租客可关联多个合同，详细记录入住/退租/续约历史

## 模块概述

<!-- kpi: 会计科目=26个[#0A3D62] | 可导出报表=10张[#F6B93B] | 税务税种=5种[#00B894] | 定时折旧=月度[#82CCDD] -->

财务管理模块涵盖账套、会计科目、记账凭证、费用核算、税务管理、预算管理、报表中心、财务看板八大子模块，并配有一整套内控与安全加固。

## 账套管理

支持**多账套并行**，每个账套独立核算。默认创建「默认主账套」，可根据管理需要创建多个分账套（按项目/业态/区域拆分）。

## 会计科目

内置**26个标准会计科目**（4级科目体系），涵盖资产类、负债类、权益类、收入类、费用类。支持科目树的父子层级展示和自定义扩展。

### 科目体系

| 类别 | 科目数量 | 示例科目 |
|------|---------|---------|
| 资产类 | 8个 | 现金/银行存款/应收账款/固定资产/累计折旧 |
| 负债类 | 5个 | 应付账款/预收租金/应交税费/其他应付款 |
| 权益类 | 3个 | 实收资本/未分配利润/本年利润 |
| 收入类 | 5个 | 租金收入/物业费收入/水电费收入/其他收入 |
| 费用类 | 5个 | 维修费/保洁费/安保费/办公费/折旧费 |

## 凭证管理

### 工作流

<!-- flow: 草稿 → 待复核 → 待审核 → 已过账 → 已作废 -->

- **自动生成**：收租到账时自动生成记账凭证（借：银行存款 / 贷：租金收入等）
- **手动录入**：支持双分录表单，科目选择器（el-tree-select），借贷金额自动平衡校验
- **状态机**：草稿→待复核→待审核→已过账→已作废，已过账只能作废、禁止回退，非法流转直接返回 400

## 费用核算

支持 **维修/保洁/安保/绿化/办公/折旧/其他** 七类费用分类管理。每笔费用关联账套和科目，审批通过后自动生成凭证；大额费用（默认 ≥5000）自动进入审批流。

## 税务管理

| 税种 | 计税方式 | 申报周期 |
|------|---------|---------|
| 增值税 | 一般纳税人/小规模纳税人 | 月/季 |
| 房产税 | 从价计征/从租计征 | 月/季/年 |
| 城镇土地使用税 | 按面积×适用税额 | 年 |
| 印花税 | 按合同金额×税率 | 次 |
| 企业所得税 | 按应纳税所得额×25% | 季/年 |

税金计算结果带 5 分钟 TTL 缓存，避免重复重算。

## 预算管理

预算编制→审批→执行→监控，支持预算科目维度的支出控制和超预算预警提醒；已批准预算禁止修改金额。

## 报表中心

- **三大主表**：资产负债表、利润表、现金流量表
- **管理报表**：收入明细表、费用分析表、账龄分析表、催缴统计表、入住率报表等，可预览/导出的报表共 10 张
- **角色矩阵**：每张报表声明可访问角色，未登记的报表一律拒绝访问（403）
- **自定义报表**：灵活选择期间范围、科目范围、对比维度

## 财务看板

<!-- kpi: 总收入[#00B894] | 总支出[#FF6B35] | 净利润[#0A3D62] | 利润率[#F6B93B] -->

实时展示关键财务指标（收入/支出/净利润/利润率/税负率），配合 ECharts 趋势图、收入构成饼图、费用分类柱状图。

## 内控与安全加固

- **写操作统一防护**：财务全部路由的每个 POST/PUT/DELETE 均同时挂 requirePermission('finance', 动作) 与 auditLog（30 个写端点 100% 覆盖）
- **不可逆操作二次确认**：发票作废/红冲/删除、资产折旧、凭证作废、账套修改等均需操作者重新输入本人密码
- **审计增强**：记录所有到达的响应，2xx 记为成功、4xx/5xx 记为失败（action 追加「(失败)」），越权尝试单独落一条「越权尝试」
- **审批引擎**：按业务类型匹配流程定义，默认预算/费用为「财务主管→总经理」，终审通过联动业务状态、驳回自动回滚

## 合同起草

- **模板选择**：从模板库中选择标准合同模板，自动填充条款
- **费用配置（billingConfig）**：可扩展 JSON 字段，支持配置租金/水费/电费/物业费分项、收款方式、银行账号、税务细则（含税类型/税率/发票类型）、违约金率、押金条款、维修责任方、解约通知期限、续约通知期限、转租许可等
- **消防约定（billingConfig.fireSafety）**：动态条款、限制项、设备清单、责任方、检查频率与违规处罚
- **房源租客关联**：选择房源和租客，自动带入相关数据
- **附件上传**：合同附件支持文档与图片，中文文件名已做编码修复

## 合同审批

审批列表支持展开行直接查看合同详情（基本信息、全部条款卡片、消防约定）。审批引擎按业务类型匹配流程定义，默认合同为「合同主管→总经理」，每级可录入审批意见，审批记录永久可追溯。

## 履行与变更

- **履行跟踪**：合同执行中自动关联房源状态、账单生成
- **变更管理**：合同条款变更需走补充协议流程，完整记录 ContractChange
- **合同看板**：八列看板（Kanban）按状态分组，拖拽式卡片管理

## 法务合规

- **条款库管理**：标准法律条款模板，确保合同条款合法合规
- **合规检查**：自动检查合同必备条款完整性、租金合理性、押金合规性
- **风险预警**：对异常条款（过高违约金、不合理免责条款）自动标红提醒
- **电子签章**：e签宝开放平台 v3 已真实实现（token 缓存 + 并发去重 + 状态映射），填入密钥即启用，未配置自动降级 Mock

## 合同模板与条款批量导入

- **模板管理**：模板按业态分类（公寓/厂房/商铺），支持按业态建立「常用条款模板-公寓/厂房/商铺」并自动同步
- **条款批量导入**：支持 Excel(.xlsx) / Word(.docx/.doc) / PDF 三种格式；PDF 走文本层解析，扫描件给出明确提示
- **智能拆分**：第X条/款/章/节 → 中文数字编号 → 阿拉伯数字编号 → 空行段落 → 单行，共五级回退
- **待处理条款桥接**：导入的条款同时写入租客 pendingClauses，新建合同时自动加载

## RBAC 权限体系

**12 个预置角色**，以模块 × 6 种操作（create/read/update/delete/approve/export）授权，路由级粗粒度隔离 + 操作级细粒度控制：

| 角色 | 主要权限（模块:动作） |
|------|----------------------|
| 管理员 | 全部模块全部动作（`*` 通配） |
| 总经理 | 全局只读 + 审批 + 导出（`*` 通配） |
| 收租主管 | rent 全量、tenant 全量、contract 只读 |
| 收租员 | rent 增查改导出、tenant 增查改 |
| 财务主管 | finance 全量、reports 查+导出 |
| 会计 | finance 增查改导出、reports 只读 |
| 出纳 | finance 查+改、rent 只读 |
| 合同主管 | contract 全量、tenant 只读 |
| 法务 | contract 查+审批、compliance 全量 |
| 物业经理 | property/workorder/facility/meter/parking/complaint/resident/announcement/vendor/inventory 全量，其余全局只读 |
| 维修工 | workorder 增查改、facility 查+改、meter 查+改 |
| 安全主管 | fire 全量、property 只读、complaint 只读 |

**权限可配置化**：role_permissions 表可按模块覆盖默认基线（模块优先于全局通配兜底），权限矩阵页面支持搜索/批量调整，保存与回退均需管理员密码二次确认；权限变更与越权尝试都会写入审计。

## 启动流程

系统启动分 4 个阶段，核心原则：**HTTP 尽早可用**（Phase 2 即监听端口）。

<!-- flow: Phase 0(日志+错误处理) → Phase 1(数据库连接+迁移+同步+管理员初始化) → Phase 2(HTTP+WebSocket启动,登录立即可用) → Phase 3(后台种子数据,幂等执行) -->

启动前后的可靠性设计：

- **单实例锁**：重复启动不再拉起第二个后端，只把已有窗口激活到前台，避免 3001 端口抢占导致「服务启动失败」误报
- **后端复用**：启动前先探测本机健康检查接口，已有健康后端直接复用
- **日志同步落盘**：启动日志同步写入，致命路径上不会丢行；弹窗诊断同时附带启动日志与 stderr
- **种子数据幂等**：演示数据受系统开关控制，历史库自动补标跳过
