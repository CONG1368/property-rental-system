## 一、检查方法说明

### 1. 相对亮度与对比度算法（WCAG 2.1）

脚本严格实现 W3C 定义的三步算法：

1. **归一化**：`c = channel / 255`
2. **线性化**（去 sRGB gamma）：`c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ^ 2.4`
3. **相对亮度**：`L = 0.2126 * R_lin + 0.7152 * G_lin + 0.0722 * B_lin`
4. **对比度**：`ratio = (L_lighter + 0.05) / (L_darker + 0.05)`，值域 [1, 21]

### 2. 半透明 Alpha 合成（玻璃拟物的关键）

WCAG 亮度公式只接受**不透明色**。本主题大量使用 rgba 半透明面，必须先做 source-over 合成再计算：

```
out = fg_rgb * alpha + bg_rgb * (1 - alpha)
```

脚本用 `flatten([最底层, ..., 最顶层])` 把整条图层栈压平。例如输入框实际渲染色是**三层叠加**：
页面渐变底 `#dde7f5` → 玻璃卡片 `rgba(255,255,255,.62)` → 输入框 `rgba(255,255,255,.6)` = **#FAFBFD**。
