## 1. 系统概述

物业租赁综合管理系统是一款面向物业管理公司与产业园区运营方的一体化桌面应用，覆盖招租获客、房源房态、签约履约、收租催缴、物业服务、消防安全与财务核算的完整业务闭环。系统安装后即可离线运行，所有数据保存在本机，无需部署服务器。

![登录页](screenshots/login.png)

### 1.1 功能地图

系统共 7 个一级菜单、86 个业务页面，按业务域划分如下。

| 一级菜单 | 覆盖能力 |
|------|------|
| 首页概览 | 全局 KPI、今日待办、收入趋势、多模块看板、系统信息 |
| 收租管理 | 房源、招租线索、入住交接、房态看板、租客档案、租客风控、租金定价、押金台账、退租管理、账单收租、收租日历、智能催缴、门锁管理、收租看板 |
| 物业管理 | 运营看板、租户服务、装修管理、维保计划、排班与质检、巡更、访客、特种设备、项目管理、经营简报、报修工单、设施设备、抄表计费、停车、投诉建议、住户档案、公告发布、公共收益、外包供应商、仓库物料 |
| 合同管理 | 合同台账、起草、审批、看板、到期、续约、模板、条款批量导入、合规检查 |
| 消防管理 | 消防看板、检查记录、器材台账、违规记录、演练记录 |
| 财务报表 | 账套、科目、凭证、费用、税务、预算、报表中心、财务看板、固定资产、银行对账、成本分摊、发票管理 |
| 系统设置 | 用户、审计日志、数据字典、打印设置、身份证读卡器、审批流程、权限矩阵、系统参数、系统运维 |

另有两个全局入口：**全局检索**（跨房源/租客/合同/账单/工单/投诉/住户/线索的统一搜索）与**审批中心**（待我审批 / 我发起的）。

### 1.2 运行特性

| 特性 | 说明 |
|------|------|
| 运行环境 | Windows 10 / 11 x64，无需安装数据库或运行时 |
| 数据库 | 内置 SQLite（零配置），可切换 MySQL |
| 数据位置 | 全部保存在本机用户目录，不上传云端 |
| 账号安全 | JWT 认证（登录态 4 小时）+ 12 角色 RBAC + 不可逆操作二次确认 |
| 实时性 | 内置 WebSocket，房态与合同变更即时推送到所有已打开的页面 |
| 自动化 | 内置 7 个定时任务（账单生成、催缴升级、合同到期、资产折旧等） |
| 导入导出 | Excel 采用 .xlsx 格式；PDF 由系统内置引擎直接生成文字版 |
| 升级方式 | NSIS 安装包覆盖安装，自动保留原有数据 |

## 2. 安装与启动

### 2.1 安装步骤

1. 双击运行安装包 `物业租赁综合管理系统-1.0.3-x64.exe`。
2. 若出现「Windows 已保护你的电脑 / 未知发布者」提示，点击「更多信息」→「仍要运行」。该提示由安装包未附加代码签名证书引起，不影响功能。
3. 选择安装目录（默认 `C:\Program Files\物业租赁综合管理系统`），点击「安装」。
4. 安装完成后桌面与开始菜单自动创建快捷方式。

覆盖升级时无需卸载旧版本：安装程序会读取注册表中的原安装路径就地升级，业务数据保存在用户目录下，不会被覆盖。

### 2.2 首次启动

首次启动时系统会依次完成：创建数据目录、建库建表、创建管理员账户、写入演示数据（房源、租客、合同、账单、门锁、消防器材、会计科目等）。

这一过程通常需要 10-30 秒，登录页会显示「正在初始化，请稍候」，初始化完成后登录按钮才可用。后续启动只需 3-5 秒。

### 2.3 数据存放位置

| 内容 | 路径 |
|------|------|
| 数据库文件 | `%APPDATA%\property-rental-system\data\database.sqlite` |
| 上传附件 | `%APPDATA%\property-rental-system\uploads\` |
| 运行日志 | `%APPDATA%\property-rental-system\logs\` |

在文件资源管理器地址栏输入 `%APPDATA%\property-rental-system` 可直接打开该目录。**卸载程序不会删除这个目录**，因此重装后数据仍在。

## 3. 登录与权限

### 3.1 默认账户

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |

首次登录后请立即在「系统设置 → 用户管理」中修改默认密码，并为每位实际使用者建立独立账号。系统禁止删除或降级最后一个管理员账号，避免出现无人可管理的情况。

登录态有效期为 4 小时，过期后会自动跳回登录页；应用在前台使用时会自动续期，无需手动重新登录。

### 3.2 角色与可访问模块

系统内置 12 个角色。菜单可见性与页面访问权由角色决定，后端接口另有一层独立校验，**前端隐藏菜单不等于接口放行，两层都会拦截**。

| 角色 | 可进入的一级菜单 |
|------|-----------|
| 管理员 | 全部（含系统设置） |
| 总经理 | 全部业务模块（只读 + 审批 + 导出），不含系统设置 |
| 收租主管 | 收租管理 |
| 收租员 | 收租管理 |
| 物业经理 | 物业管理 |
| 维修工 | 物业管理（工单与设施相关） |
| 财务主管 | 财务报表 |
| 会计 | 财务报表 |
| 出纳 | 财务报表 |
| 合同主管 | 合同管理 |
| 法务 | 合同管理 |
| 安全主管 | 消防管理 |

### 3.3 操作级权限

在模块可见的前提下，系统进一步按 6 种动作控制具体按钮：新增、查看、修改、删除、审批、导出。典型差异如下。

| 角色 | 权限要点 |
|------|------|
| 收租主管 | 收租模块全权限；合同只读 |
| 收租员 | 收租模块可新增/修改/导出，**不能删除** |
| 财务主管 | 财务全权限，含审批与导出 |
| 会计 | 财务可录入、修改、导出，**不能删除、不能审批** |
| 出纳 | 财务仅查看与修改（如登记收款），**不能新增、删除、审批** |
| 法务 | 合同只读 + 审批；合规模块可修改与导出 |
| 维修工 | 工单可新增/修改，设施与抄表仅可修改，**不能删除** |
| 安全主管 | 消防模块全权限；物业与投诉只读 |

管理员可在「系统设置 → 权限矩阵」中按角色逐模块调整上述权限，调整结果实时生效，无需重启。

### 3.4 不可逆操作的二次确认

删除发票、发票作废与红冲、资产删除与折旧、凭证作废、账套修改、费用审批、权限变更、删除字典、重置用户密码、下载数据备份等操作，会弹出对话框要求**操作者再次输入本人登录密码**。这是防止误操作和他人借用已登录电脑的最后一道防线，输入的是当前登录者自己的密码，而不是管理员密码。

## 4. 界面与导航

系统采用「左侧菜单 + 顶部工具栏 + 主内容区」的经典布局。

- **左侧菜单**：按角色自动过滤，无权限的模块不会出现。点击一级菜单展开二级页面。
- **顶部工具栏**：全局搜索框、消息通知铃铛（未读数量红点）、当前用户与角色标识、退出登录。
- **面包屑**：主内容区左上角显示「首页 / 当前模块 / 当前页面」，点击可回退。
- **列表页通用交互**：顶部为筛选条件，中部为数据表格，底部为分页。首次加载显示骨架屏，无数据时显示统一空状态并给出下一步引导按钮。
- **实时刷新**：房态变更、合同状态变更等事件由后台实时推送，相关页面自动更新，无需手动刷新。

### 4.1 全局检索

菜单最下方的「全局检索」提供一个搜索框，跨房源、租客、合同、账单、工单、投诉、住户、线索统一检索，结果按类型分组展示，点击直接跳转到对应记录。顶部工具栏的搜索框是同一入口。

![全局检索](screenshots/search.png)

### 4.2 审批中心

汇总与当前登录者相关的审批事项，分两个页签：

- **待我审批**：需要本人处理的单据，可直接同意或驳回并填写审批意见。
- **我发起的**：本人提交的审批单及其当前进度。

也可在此直接发起新的审批申请。

![审批中心](screenshots/approval-center.png)

## 6. 收租管理

### 6.1 房源管理

维护全部租赁标的的基础档案。

![房源管理](screenshots/properties.png)

- 房源类型：公寓、厂房、商铺；可另填子类型与业主。
- 房源状态共 9 种：空置、已锁定、已预订、已出租、退租中、待保洁、待验收、维修中、已冻结。
- 支持按名称、类型、状态、楼栋筛选；点击行进入房源详情，可查看关联合同、租客与状态变更历史。

**批量导入**：进入「房源管理 → 批量导入」，先点击「下载模板」，按模板填写后上传。

| 要求 | 说明 |
|------|------|
| 文件格式 | 仅支持 .xlsx（老版 .xls 请在 Excel/WPS 中先另存为 .xlsx） |
| 文件大小 | 不超过 10 MB |
| 表头位置 | 第一行为表头 |
| 可识别列 | 名称、类型、面积、地址、楼层、单元、楼栋、房号、楼栋排序、楼层排序、子类型、业主 |

上传后会先进入预览表格，确认无误再点击「确认导入」，避免脏数据直接落库。

### 6.2 房态看板

以楼栋、楼层为维度可视化展示全部房间。

![房态看板](screenshots/room-kanban.png)

- 9 种房态用不同颜色区分，卡片上直接显示租客姓名、到期日与门锁图标。
- 顶部可按楼栋、楼层筛选；筛选在本地完成，切换无延迟。
- 点击房间卡片打开快捷操作抽屉，可查看该房间的状态变更时间线并直接变更状态。
- 勾选多个房间后可执行「批量变更状态」。
- 任何人变更房态，其他已打开该页面的电脑会实时同步。

**房态流转规则**：系统按状态机校验，非法流转会被拒绝并提示。例如「已出租」只能转为「退租中」或「已冻结」，不能直接转回「空置」；正确路径是「已出租 → 退租中 → 待保洁 → 待验收 → 空置」。

**批量生成房间**：进入「房态看板 → 批量生成」，填写楼栋名称、起止楼层、每层房间数、命名规则与默认面积，一次性建出整栋楼的房间档案。

### 6.3 房态数据大屏

深色主题的可视化大屏，适合投放到会议室或值班室显示器。

![房态数据大屏](screenshots/room-dashboard.png)

包含房态分布玫瑰图、楼栋对比柱图、入住率仪表盘、楼层热力图、趋势线、房态流转桑基图与告警跑马灯。

### 6.4 租客管理

维护租客档案，支持身份证读卡器一键录入。

![租客管理](screenshots/tenants.png)

- 基础信息之外，还可保存性别、出生日期、民族、身份证地址、签发机关、有效期起止与证件照片。
- **身份证号唯一**：重复录入会被拒绝并提示已存在，避免同一人建出多份档案。
- 已关联有效合同的租客不允许删除，需先处理合同。
- 详情页汇总该租客的合同、账单、押金与缴费记录，并支持打印租客信息表。

### 6.5 招租线索

以漏斗方式跟进意向客户，顶部五张卡片分别统计新线索、已联系、已看房、已成交、已流失。

- 登记字段：客户姓名、手机、意向业态（公寓/厂房/商铺）、意向面积、预算、来源渠道、下次跟进日期。
- 来源渠道可选 58同城、贝壳、小红书、抖音、线下、转介绍、其他，便于统计获客成本。
- 行操作「跟进」记录沟通内容并推进状态；「看房」登记带看安排，看房状态含已预约、已完成、已取消、爽约。

### 6.6 入住交接

以「执行中」的合同为源头登记入住交接，交接清单固定为 6 项：水表底数、电表底数（需填写具体底数）、钥匙交接、门禁卡、家具家电完好、房屋状况。

登记押金金额后点击「交接」并确认，状态由「待交接」变为「已完成」。水电底数是日后抄表计费与退租核对的基准，务必如实填写。

### 6.7 租客风控

对全部租客给出信用评分与 A/B/C/D 四级评级，并按分数给出文字建议。

![租客风控](screenshots/tenant-credit.png)

- 顶部卡片：租客总数、平均评分、优质租客（A/B）、高风险（C/D）。
- 可对单个租客「重新评估」，也可「批量重新评估」全量刷新。
- 建议在续约、调价、押金比例决策前先看此页。

### 6.8 租金定价

提供两个工具：

- **定价推荐**：输入业态、面积（㎡）与单价（元/㎡），点击「计算推荐月租」得到建议租金。
- **批量调价**：勾选执行中的合同，填写调价比例（正数为涨、负数为降），点击「执行调价」批量生效。

### 6.9 押金台账

![押金台账](screenshots/deposits.png)

- 列出每笔押金的押金金额、已退还、已扣除与**可退余额**，状态含在管、部分退还、已退还、已抵扣。
- 操作：登记押金、退还、扣除、详情。
- 顶部卡片：押金笔数、在管笔数、已退还金额、已扣除金额。

### 6.10 退租管理

![退租管理](screenshots/checkouts.png)

退租按「待处理 → 已受理 → 交接中 → 已完成」推进，中途可取消。

1. 提交退租申请（选择合同并填写退租原因）。
2. 「受理」确认受理，「开始交接」进入现场交接。
3. 处理弹窗中填写交接清单、费用清算（每条含项目、类型「扣除/退还」、金额）与押金退还金额。
4. 点击「完成」执行退租结算，系统会同时**终止合同、将租客置为退租、把房源转为「待保洁」**，操作前会弹出该提示确认。

### 6.11 收租管理（账单）

账单的生成、收款登记与打印。

![收租管理](screenshots/bills.png)

- 支持按月份、状态（未缴 / 部分缴 / 已缴 / 逾期）组合筛选，状态可多选。
- 一张账单支持多笔收款，累计收款达到应收金额后自动置为已缴。
- 逾期账单自动计算违约金，费率在合同细则中约定。
- 每行可直接打印：已缴打印收据，未缴打印账单。

### 6.12 收租日历

以月历形式展示每天到期的账单数量与金额，点击某一天查看当天明细，适合安排上门收租路线。

![收租日历](screenshots/bills-calendar.png)

### 6.13 智能催缴

按逾期天数自动分级，避免人工判断遗漏。

### 8.3 条款批量导入

![条款批量导入](screenshots/clause-import.png)

- **Word / PDF 模式**：上传 .docx、.doc 或 .pdf，系统自动提取正文文本，再由「智能拆分」按「第X条 / 中文数字编号 / 阿拉伯数字编号 / 空行段落」四级规则切成条款，人工确认后选择目标租客导入。

上传限制：单个文件不超过 20 MB；表格仅支持 .xlsx（老版 .xls 请先另存为 .xlsx）；扫描件 PDF 因无文字层无法提取，需改用可复制文字的 PDF。

### 8.4 合同审批

### 8.6 到期与续约

- **续约管理**：对到期合同发起续约，自动复制原合同条款，仅需填写新的到期日与租金。

## 10. 财务报表

### 10.1 账套与科目

- **账套管理**：支持多账套独立核算，修改账套需二次确认。
- **科目管理**：系统初始化时自动建立 26 个标准会计科目，可按编码或名称检索，也可自行增补。

### 10.2 凭证管理

![凭证管理](screenshots/finance-vouchers.png)

- 录入时自动校验借贷平衡，不平衡不允许保存。
- 凭证状态机：草稿 → 待复核 → 待审核 → 已过账 → 已作废。**已过账的凭证只能作废，不能回退到之前的状态**，非法流转会被拒绝。
- 作废凭证需要二次确认密码。
- 收款、退款等业务会自动生成凭证；自动生成失败只记录告警，不会影响收款本身。

### 10.3 费用核算与预算

- **费用核算**：登记物业日常费用，必须指定所属账套。金额达到大额阈值（默认 5000 元）的费用会自动进入审批流（财务主管 → 总经理）。
- **预算管理**：预算状态为编制中、待审核、已批准。**已批准的预算不允许再修改金额**，需要变更时应走新的编制流程。执行进度按实际金额与预算金额对比展示。

### 10.4 发票管理

![发票管理](screenshots/finance-invoices.png)

发票状态机严格受控：

| 操作 | 允许的前置状态 |
|------|------|
| 开票 | 仅「待开票」 |
| 作废 | 非「已作废」且非「已红冲」 |
| 红冲 | 仅「已开票」 |

作废、红冲、删除均需二次确认密码。发票号冲突时系统自动重试生成，最多 3 次。

### 10.5 固定资产

![固定资产](screenshots/finance-fixed-assets.png)

- 登记资产原值、残值、使用年限与折旧方法。
- 每月 1 日凌晨自动计提折旧；也可手动触发（需二次确认）。
- **同一期间不会重复计提**：系统按「已折旧期间」水位线跳过本期已处理的资产，累计折旧另有「原值 − 残值」封顶，不会折过头。

### 10.6 银行对账与成本分摊

- **银行对账**：上传银行流水（支持 .xlsx 与 .csv，单文件不超过 5 MB），系统按金额、日期、摘要自动匹配系统内收款记录，未匹配项人工处理。
- **成本分摊**：将公共成本按面积、户数等规则分摊到各房源或账套。

### 10.7 税务管理

按计税方式与税率测算应纳税额，支持导出申报数据。计算结果有 5 分钟缓存，短时间内重复查询不会重复计算。

### 10.8 报表中心

![报表中心](screenshots/reports.png)

- 财务报表：资产负债表、利润表、现金流量表。
- 经营报表：入驻率报表、账龄分析、欠费明细、收缴率分析等。
- 支持导出 Excel（.xlsx）与 PDF。
- **报表可见性按角色控制**：每张报表都声明了可访问角色，未登记角色一律拒绝访问。

### 10.9 财务看板

![财务看板](screenshots/finance-dashboard.png)

财务数据可视化大屏，含收入支出趋势、费用结构、预算执行等。

## 11. 系统设置

系统设置仅管理员可见。

### 11.1 用户管理

![用户管理](screenshots/settings.png)

- 新建用户时必须从 12 个预定义角色中选择，非法角色会被拒绝。
- 删除用户、重置用户密码均需二次确认密码。
- **最后一名管理员受保护**：不能被删除，也不能被降级为其他角色，且管理员不能删除自己。

### 11.2 权限矩阵

![权限矩阵](screenshots/permissions.png)

按「角色 × 模块 × 动作」调整权限：

- 支持搜索模块、批量勾选整行或整列。
- 保存与回退默认值前都需要输入管理员密码确认。
- 未定制的模块自动沿用系统默认权限，定制后立即生效。
- 所有权限变更都会写入审计日志。

### 11.3 审计日志

![审计日志](screenshots/audit-logs.png)

- 记录所有到达系统的操作：成功（2xx）记原动作名，失败（4xx/5xx）在动作名后追加「(失败)」标记；越权尝试额外单独记录。
- 支持按模块、操作人、动作、关键字、成功/失败状态与日期范围筛选。
- 可导出 CSV（带 BOM，Excel 打开不乱码）。
- 如需临时关闭审计，可在系统运维页切换开关（需二次确认）。

### 11.4 数据字典

维护下拉选项的取值来源（如费用类型、投诉类型等）。删除字典类型或字典项属于级联破坏性操作，均需二次确认并记入审计。

### 11.5 系统参数

![系统参数](screenshots/system-params.png)

集中管理系统配置项，按分组筛选，支持新增、修改、批量保存。标记为敏感的参数（如第三方密钥）在界面上打码显示。系统内置参数不允许删除。布尔类型参数在编辑时显示为「开/关」开关。

**是否生成演示数据（demo_enabled）**：位于分组「系统」。默认开启（首次安装/空库会生成一套演示数据）；关闭后重启，整套演示数据（房源、租客、合同、账单、门锁、消防、读卡器）都不会再生成或重建。配套的内部标记 demo_seeded 记录演示数据是否已初始化，为只读信息，一般不修改。

### 11.6 打印设置

![打印设置](screenshots/print-settings.png)

配置打印模板抬头：公司全称、公司 Logo、电子签章、证件类型、证件号码、联系电话，右侧实时预览合同抬头效果。Logo 与签章以图片形式保存在数据库中，随打印模板一起输出。

**非管理员角色也能读取这些配置**（打印合同时需要），但只有管理员能修改。

### 11.7 身份证读卡器

管理读卡器设备，支持华视、新中新、普天、精伦、中控等品牌，接口类型含 USB、串口、蓝牙、WiFi，状态含在线、离线、故障、未激活。租客录入页的「读卡」按钮会自动选择一台在线设备。读卡结果会做身份证校验位验证与重复检测，并写入读卡审计日志（身份证号脱敏保存）。

### 11.8 审批流程

配置各业务类型的审批链路。系统默认提供：合同（合同主管 → 总经理）、预算与费用（财务主管 → 总经理）。未配置流程的业务类型会直接跳过审批，不会卡单。

### 11.9 系统运维

![系统运维](screenshots/system-ops.png)

| 功能 | 说明 |
|------|------|
| 系统信息 | 版本号、Node 版本、平台、内存占用、数据库类型、用户数、已运行时长 |
| 定时任务 | 查看调度器真实运行状态与每个任务的上次执行时间，可逐个「立即执行」，也可整体启停（需二次确认） |

## 13. 自动化与通知

### 13.1 内置定时任务

系统内置 7 个定时任务，随应用启动自动挂载，可在「系统运维」页查看状态或手动触发。

| 任务 | 执行时间 | 作用 |
|------|------|------|
| 账单生成 | 每日 02:00 | 按合同周期生成应收账单，同合同同期间已存在则跳过 |
| 催缴升级 | 每日 08:00 | 按逾期天数重算催缴等级 |
| 合同到期检查 | 每日 07:00 | 更新到期与预到期合同状态 |

### 13.2 通知渠道

## 14. 数据维护与备份

### 14.1 日常备份（推荐）

进入「系统设置 → 系统运维 → 数据备份」，输入密码确认后下载数据库副本，妥善保存到移动硬盘或网络盘。建议每周至少备份一次，重要操作（批量导入、批量调价、批量删除）之前额外备份一次。

### 14.2 手工备份

关闭应用后，直接复制以下整个目录即可完成完整备份（含附件）：

`%APPDATA%\property-rental-system\`

恢复时把该目录复制回原位置再启动应用。**复制数据库文件时必须先关闭应用**，否则可能拷到不完整的状态。

### 14.3 升级与数据兼容

新版本启动时会自动检测并补齐数据库中缺失的字段，无需人工干预，历史数据不会丢失。因此升级前的备份主要用于防范意外，而不是升级必需步骤。

### 14.4 切换到 MySQL

如需多机共用一套数据，可在配置文件中把数据库方言改为 MySQL 并填写连接信息，重启后系统会在 MySQL 中自动建表。此场景需由 IT 人员操作。

## 15. 常见问题

**Q：忘记管理员密码怎么办？**
A：若还有其他管理员账号，请用该账号在「用户管理」中重置密码。若所有管理员密码都已丢失，只能删除 `%APPDATA%\property-rental-system\data\database.sqlite` 后重启应用，系统会重建数据库并恢复默认账户 admin/admin123 —— **此操作会清空全部业务数据，请务必先备份该文件**。

**Q：安装时提示「Windows 已保护你的电脑 / 未知发布者」？**
A：安装包未附加代码签名证书，属正常现象。点击「更多信息」→「仍要运行」即可。如需彻底消除该提示，需要为安装包购买并配置代码签名证书。

**Q：启动后提示「后端异常」或登录按钮点不动？**
A：首次启动需要初始化数据库和演示数据，等待 10-30 秒即可。若长时间不恢复，请检查 3001 端口是否被其他软件占用，或查看 `%APPDATA%\property-rental-system\logs\` 下的日志。

**Q：上传 Excel 提示「仅支持 .xlsx」？**
A：系统统一使用 .xlsx 格式，不再支持老版 .xls 二进制格式。请在 Excel 或 WPS 中打开原文件，选择「另存为」→ 文件类型选「Excel 工作簿 (.xlsx)」后重新上传。

**Q：房源导入失败或数据不对？**
A：请先在导入页下载模板，保证第一行是表头且列名与模板一致（名称、类型、面积、地址、楼层、单元、楼栋、房号等）。上传后先看预览表格再确认导入。单个文件不超过 10 MB。

**Q：为什么房态不能从「已出租」直接改成「空置」？**
A：房态受状态机约束，必须按「已出租 → 退租中 → 待保洁 → 待验收 → 空置」流转，以保证退租、保洁、验收环节都有记录可查。

**Q：删除租客时提示不允许？**
A：该租客名下还有合同。请先处理（终止或删除）其合同，再删除租客。

**Q：条款批量导入找不到租客？**
A：Excel 中的「租客姓名」列必须与系统中已录入的租客姓名完全一致（含空格与全半角）。Word / PDF 模式则需要手动选择目标租客。

**Q：上传的 PDF 提取不出条款文字？**
A：扫描件 PDF 本质是图片，没有文字层，系统无法提取。请使用可复制文字的电子版 PDF，或改用 Word 文档。

**Q：打印合同出现乱码或排版错位？**
A：请确认系统已安装「宋体」和「微软雅黑」字体。桌面版导出的是文字版 PDF，若在第三方阅读器中显示异常，可先用系统自带的 PDF 阅读器或浏览器打开确认。

**Q：明明有权限，按钮却提示「权限不足」？**
A：权限可能被管理员在「权限矩阵」中定制过。请让管理员检查该角色在对应模块的动作勾选情况；越权尝试也会记录在审计日志中，可据此排查。

**Q：消防器材过期提醒不准确？**
A：请确认器材的「有效期至」与「下次检查日期」填写正确，系统按下次检查日期判断是否进入「即将过期」（30 天内）。

**Q：定时任务好像没跑？**
A：进入「系统设置 → 系统运维 → 定时任务」查看调度器实际运行状态与每个任务的上次执行时间，可点击「立即执行」手动补跑。注意应用必须处于运行状态，关闭应用后定时任务不会执行。

**Q：数据能多台电脑共用吗？**
A：默认的 SQLite 模式是单机本地库，不支持多机共享。多机共用需切换到 MySQL 并由 IT 人员完成部署。
