## 1. 系统概述

物业租赁综合管理系统是一款面向物业管理公司的全功能桌面应用，覆盖房源管理、租客签约、收租催缴、合同全生命周期、消防安全管理和财务核算等全业务流程。

![登录页](screenshots/login.png)

### 核心功能模块

| 模块 | 功能 |
|------|------|
| 租赁管理 | 房源、房态看板、批量生成、租客、账单、催缴、门锁、收租看板 |
| 合同管理 | 起草、审批、履行、续约、到期、模板、合规、条款导入、打印 |
| 消防管理 | 消防看板、检查记录、器材台账、违规记录、演练记录 |
| 财务管理 | 账套、科目、凭证、费用、税务、预算、报表、财务看板 |
| 系统设置 | 用户管理、身份证读卡器、审计日志、打印设置 |

### 技术特点

| 特性 | 说明 |
|------|------|
| 运行环境 | Windows 10/11 x64 |
| 数据库 | 内置 SQLite（零配置），可选 MySQL |
| 用户界面 | Vue3 + Element Plus 现代化桌面应用 |
| 数据安全 | 本地存储，JWT 认证 + RBAC 9 角色权限 |
| 更新方式 | NSIS 安装包，支持覆盖升级 |

## 2. 安装与启动

### 安装步骤

1. 双击运行 `物业租赁综合管理系统-x.x.x-x64.exe` 安装程序
2. 选择安装目录（默认 `C:\Program Files\物业租赁综合管理系统`）
3. 安装完成后桌面自动创建快捷方式
4. 双击桌面图标或从开始菜单启动应用

### 首次启动

首次启动时系统会：
- 在 `%APPDATA%/物业租赁综合管理系统/` 下创建数据目录
- 初始化 SQLite 数据库并创建管理员账户
- 生成演示数据（房源、租客、合同、账单、消防器材等）

首次启动可能需要 10-30 秒，后续启动只需 3-5 秒。启动过程中登录页会显示"正在初始化演示数据，请稍候..."。

## 5. 租赁管理

管理所有租赁房源信息，支持增删改查。

![房源管理](screenshots/properties.png)

### 5.2 房态看板

可视化展示所有房源状态，按楼栋和楼层分组。

![房态看板](screenshots/room-kanban.png)

- 颜色区分 9 种房源状态
- 支持网格视图和表格视图
- 点击房间卡片进入快捷操作抽屉
- 支持批量状态变更
- 实时 WebSocket 推送状态更新

### 5.3 租客管理

管理租客档案，含身份证信息录入和读卡器支持。

### 5.4 收租管理

账单生成、收款记录、打印收据/账单。

![收租管理](screenshots/bills.png)

- 按月份/状态筛选账单
- 支持多笔收款记录
- 滞纳金自动计算
- 支持收据和账单打印

按逾期天数自动分级催缴。

### 5.6 门锁管理

管理智能门锁和传统门锁，支持远程开锁、密码管理和钥匙借还。

![门锁管理](screenshots/door-locks.png)

### 5.7 收租日历

日历视图展示每月账单到期情况。

### 5.8 收租看板

## 6. 合同管理

### 6.1 合同列表

展示所有合同，支持多状态筛选和批量操作。

![合同列表](screenshots/contracts.png)

### 6.2 合同起草

新建合同时填写基本信息、费用配置、合同细则、消防安全约定和合同条款。

![合同起草](screenshots/contract-draft.png)

**消防安全约定**：在起草合同时可配置消防责任方、配备器材、禁止事项和违规处罚措施。消防条款和限制支持动态增删。

**合同附件上传**：新建合同自动创建草稿后，即可上传合同附件（支持 PDF/Word/图片/Excel）。

### 6.3 条款批量导入

支持从 Excel / Word / PDF 文件中批量导入条款到租客合同。

![条款批量导入](screenshots/clause-import.png)

- **Excel 模式**：上传含租客姓名、条款标题、条款内容的表格，自动匹配租客并追加到其有效合同
- **Word/PDF 模式**：上传文档自动提取文本，手动选择目标租客后导入

### 6.4 合同审批

多级审批流程：起草中 → 审批中 → 已签订/已驳回。

### 6.5 合同看板

合同状态可视化大屏，含到期预警、续约提醒等。

### 6.6 到期管理

展示即将到期合同列表，支持按时间范围筛选。

### 6.7 续约管理

对到期合同进行续约操作，自动复制原合同条款。

### 6.8 模板管理

管理合同模板及预定义条款，新建合同时可直接选用。

### 6.9 合规管理

合同合规性检查，自动检测缺失必要条款等问题。

## 7. 消防管理

消防管理模块提供完整的日常消防安全管理能力。

### 7.1 消防看板

消防综合数据一览。

![消防看板](screenshots/fire-dashboard.png)

- KPI 卡片：器材总数、即将过期/已过期数、待整改违规数、本月检查次数
- 器材状态分布、检查结果统计、违规严重程度分布
- 即将过期器材列表（30 天内）
- 待整改违规列表
- 快捷入口直达各子功能

### 7.2 检查记录

管理消防检查记录，支持按房源、检查结果、日期范围筛选。

![检查记录](screenshots/fire-inspections.png)

- 6 项检查维度：灭火器、烟感报警器、应急照明、疏散通道、电气线路、易燃易爆管理
- 检查结果：合格 / 不合格 / 限期整改
- 综合评分 0-100 分
- 支持上传检查照片附件
- 查看关联违规记录

### 7.3 器材台账

管理各房源消防器材的采购、维护和报废。

![器材台账](screenshots/fire-equipment.png)

- 器材类别：灭火器、消火栓、烟感报警器、应急照明、疏散标志、防火门、自动喷淋等
- 状态跟踪：正常、即将过期、已过期、待维修、已报废
- 过期/即将过期行以红色/黄色高亮标记
- 记录有效期、检查日期、下次检查日期

### 7.4 违规记录

记录和跟踪消防违规整改情况。

![违规记录](screenshots/fire-violations.png)

- 违规类别：器材缺失、通道堵塞、电气隐患、易燃易爆、擅自改造等
- 严重程度：一般隐患、重大隐患、紧急
- 整改流程：待整改 → 整改中 → 已整改/逾期未改
- 支持罚款金额录入
- 逾期未改红色标记

### 7.5 演练记录

记录消防演练信息。

![演练记录](screenshots/fire-drills.png)

- 演练类型：疏散演练、灭火演练、综合演练、桌面推演
- 记录参与人数、用时、评分
- 总结发现问题和改进措施

## 10. 常见问题

**Q：忘记管理员密码怎么办？**
A：删除 `%APPDATA%/物业租赁综合管理系统/data/database.sqlite` 文件后重启应用，系统会自动重建数据库并创建默认账户 admin/admin123。注意此操作会清除所有数据。

**Q：如何切换数据库？**
A：在 `.env` 文件中设置 `DB_DIALECT=mysql` 并配置 MySQL 连接信息。

**Q：打印合同出现乱码？**
A：确保系统安装了"宋体"和"微软雅黑"字体。PDF 导出使用 `html2canvas` 截图方式，原生打印使用 Electron 内置打印，推荐使用"直接打印"模式获得最佳排版效果。

**Q：消防器材过期提醒不准确？**
A：请确保器材的"有效期至"和"下次检查日期"字段正确填写，系统根据下次检查日期判断即将过期状态（30 天内）。

**Q：条款批量导入找不到租客？**
A：Excel 中的"租客姓名"列需与系统中已录入的租客姓名完全一致。Word/PDF 模式请手动选择租客。
