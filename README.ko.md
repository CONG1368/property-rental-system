# 부동산 임대 종합 관리 시스템

부동산 임대 관리를 위한 풀스택 데스크톱 애플리케이션으로, 자산 관리, 임차인 관리, 임대료 수금 및 독촉, 계약 생애주기, 부동산 운영, 소방 관리, 재무 회계 및 보고서 분석을 포괄합니다.

> **어떠한 형태의 상업적 사용도 엄격히 금지됩니다**

| 계층 | 기술 |

| 프론트엔드 프레임워크 | Vue 3.5 Composition API + TypeScript |

## 빠른 시작

### 필수 조건

- Node.js ≥ 18
- npm ≥ 9

### 설치 및 실행

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서비스 시작 (프론트엔드 + 백엔드 동시)
npm run dev
```

- 프론트엔드: http://localhost:5173
- 백엔드: http://localhost:3001
- 기본 로그인: `admin / admin123`

### 빌드 및 패키징

```bash
npm run build          # 전체 빌드 (프론트엔드 → 백엔드 → Electron)
npm run build:electron # Electron 설치 프로그램만 패키징
```

> 패키징 전에 dev를 중지하세요(`backend/node_modules`, `runtime/node/node.exe` 잠김 → EPERM). `electron-builder.yml`은 `compression: normal` + NSIS 단일 대상이며 실측 약 6분 소요. 산출물은 `release/`(`property-rental-system-setup-<version>.exe` + blockmap + `latest.yml`)이며 zip 배포본은 생성하지 않습니다.

### 데이터베이스 전환

기본값은 SQLite(설정 불필요). MySQL로 전환하려면 `backend/.env` 파일을 편집:

```env
DB_DIALECT=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=property_rental
```

## 외부 서비스

네 가지 알림 서비스는 모두 **자체 개발한 실제 구현이며 서드파티 SDK가 없습니다** (Node 내장 모듈과 전역 `fetch`만 사용). `.env`에 계정 키를 입력하면 활성화되고, **미설정 시 자동으로 Mock으로 강등되어 로그를 기록하며 비즈니스 흐름을 절대 중단하지 않습니다**:

| 서비스 | 구현 요점 | 미설정 시 |
|------|---------|---------|
| SMS 알림 | 알리바바 클라우드 V1 서명 (HMAC-SHA1) + 텐센트 클라우드 TC3-HMAC-SHA256 | Mock 로그 기록 |
| 전자 서명 | e签宝 오픈 플랫폼 v3 (token 캐시 + 동시성 중복 제거 + 상태 매핑) | Mock 로그 기록 |
| 이메일 알림 | 내장 SMTP 클라이언트 (node:tls/net, STARTTLS + RFC 2047 중국어 제목) | Mock 로그 기록 |
| 위챗 알림 | 공식 계정 템플릿 메시지 (access_token 캐시 + 40001 자동 재시도) | Mock 로그 기록 |
| 신분증 리더기 | 화시 CVR-100U: 32비트 Python 브리지 + 내장 WHQL 드라이버 + 구조화 API | Mock 모드 전환 가능 |
| 스마트 수도/전력 계량기 | bzp.iyunmu.com 선불 플랫폼 연동, 세션 창 내 토큰 동기화 | 플랫폼 계정 필요 |
| 은행 대사 / 결제 콜백 | 예약된 Provider 인터페이스 | Mock 로그 기록 |

알고리즘 자체 점검 (실제 계정 불필요): `cd backend && npx tsx ../scripts/verify-external-providers.ts` (21개 케이스).
