# 부동산 임대 관리 시스템

부동산 임대 관리를 위한 풀스택 데스크톱 애플리케이션으로, 자산 관리, 임차인 관리, 임대료 수금 및 독촉, 계약 생애주기, 재무 회계 및 보고서 분석을 포괄합니다.

> **어떠한 형태의 상업적 사용도 엄격히 금지됩니다**
> (판매, 라이선스, 임대, 상업적 호스팅, SaaS 서비스, 상용 제품 통합 등을 포함하되 이에 국한되지 않음).

## 기술 스택

| 계층 | 기술 |
|---|------|
| 프론트엔드 | Vue 3 Composition API + TypeScript |
| UI 라이브러리 | Element Plus |
| 차트 | ECharts 5 + vue-echarts |
| 상태 관리 | Pinia |
| 백엔드 | Express + TypeScript |
| ORM | Sequelize 6 (기본 SQLite, MySQL 선택 가능) |
| 인증 | JWT (액세스 4h + 갱신 7d) |
| 스케줄 작업 | node-cron (청구서 생성/독촉/감가상각/계약 만료) |
| 실시간 통신 | WebSocket |
| 데스크톱 패키징 | Electron + electron-builder (NSIS 설치 프로그램) |

## 빠른 시작

### 필수 조건

- Node.js ≥ 18
- npm ≥ 9

### 설치 및 실행

```bash
# 1. 의존성 설치
npm install

# 2. 개발 서비스 시작 (프론트엔드 + 백엔드 동시)
npm run dev
```

- 프론트엔드: http://localhost:5173
- 백엔드: http://localhost:3001
- 기본 로그인: `admin / admin123`

### 빌드 및 패키징

```bash
npm run build          # 전체 빌드 (프론트엔드 → 백엔드 → Electron)
npm run build:electron # Electron 설치 프로그램만 패키징
```

### 데이터베이스 전환

기본값은 SQLite(설정 불필요). MySQL로 전환하려면 `backend/.env` 파일을 편집:

```env
DB_DIALECT=mysql
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=yourpassword
DB_NAME=property_rental
```

## 프로젝트 구조

```
├── frontend/                  # Vue3 프론트엔드
│   └── src/
│       ├── api/               # API 요청 모듈
│       ├── components/        # 공통 컴포넌트
│       ├── router/            # 라우터 (해시 모드)
│       ├── stores/            # Pinia 상태 관리
│       └── views/             # 페이지 컴포넌트
│           ├── dashboard/     # 홈 대시보드
│           ├── rent/          # 임대 관리
│           ├── finance/       # 재무 관리
│           ├── contract/      # 계약 관리
│           └── system/        # 시스템 설정
├── backend/                   # Express 백엔드 (ESM)
│   └── src/
│       ├── models/            # Sequelize 모델 (28개 이상)
│       ├── routes/            # API 라우트 (24개 이상 모듈)
│       ├── services/          # 비즈니스 서비스 계층 (19개 이상 서비스)
│       ├── middleware/        # 미들웨어 (인증/감사/유효성 검사/속도 제한)
│       ├── jobs/              # 크론 작업 스케줄러
│       └── websocket/         # WebSocket 실시간 푸시
├── electron/                  # Electron 메인 프로세스
├── scripts/                   # 유틸리티 스크립트
├── electron-builder.yml       # 패키징 설정
└── package.json               # 루트 설정
```

## 기능 목록

### 임대 관리

| 기능 | 설명 |
|------|------|
| 자산 관리 | 자산 정보 등록, 상태 추적, 면적/평면/요금 기준, 일괄 가져오기 |
| 임차인 관리 | 임차인 정보, 계약 연계, 신용 점수 |
| 임대료 수금 | 청구서 생성, 수동 작성, 수납 기록, 비용 상세 (임대료/수도/전기/관리비/기타) |
| 스마트 독촉 | 3단계 독촉 에스컬레이션, 독촉 작업 추적, 연체 표시 |
| 도어락 관리 | 스마트락 (원격 잠금해제/비밀번호 관리/배터리 모니터링), 전통식 자물쇠 (키 대여반납/분실신고/폐기 워크플로우), 감사 로그 |
| 인쇄 | 계약서/영수증/청구서/임차인 정보 인쇄, 시스템 네이티브 인쇄 및 PDF 내보내기, A4/감열 영수증 형식 |
| 수금 대시보드 | 징수율, 연체율, 결제 채널 분포, 임대료 추이 |
| 수금 캘린더 | 월간 수금 캘린더 보기, 일괄 상태 개요 |

### 계약 관리

| 기능 | 설명 |
|------|------|
| 계약 목록 | 전체 생애주기: 초안/승인/서명/이행/만료 |
| 계약 작성 | 양식 기반 생성, 비용 설정 (수도/전기/관리비), 자산-임차인 연결 |
| 계약 승인 | 제출/반려/서명 워크플로우, 승인 기록 감사 추적 |

| 계약 칸반 | 상태별 8열 칸반 |

| 만료 캘린더 | 월간 만료 계약 보기, 다단계 만료 통계 |
| 계약 템플릿 | 템플릿 관리 |
| 규정 준수 | 계약 규정 준수 검토 |
